Bagaimana Enkripsi Hybrid Bekerja?

File Anda melalui 4 lapis pengamanan kriptografis secara otomatis sebelum disimpan atau dikirim.

1

1. Hashing Dokumen

File diproses dengan fungsi SHA-256 untuk menghasilkan sidik jari digital (hash) 256-bit unik yang mewakili integritas file asli.

2

2. Enkripsi AES-256

Seluruh isi payload dokumen dienkripsi super cepat menggunakan kunci simetris AES-256 CBC acak yang dibuat dinamis saat itu juga.

3

3. Bungkus Kunci RSA

Kunci AES rahasia dienkripsi dengan kunci publik RSA-2048 OAEP. Hanya pemilik kunci privat RSA yang bisa membuka kunci AES tersebut.

4

4. Tanda Tangan ECC

File terenkripsi ditandatangani dengan kunci privat ECC (ECDSA) untuk menjamin autentikasi asal, non-repudiation, dan proteksi dari manipulasi.

Kekuatan Tiga Pilar Kriptografi

Setiap algoritma memiliki keunggulan khusus yang saling melengkapi dalam sistem hybrid ini.

Simetris 256-Bit

AES (Advanced Encryption Standard)

Standar enkripsi data yang diadopsi pemerintah AS. Ideal untuk mengenkripsi file berukuran besar secara cepat tanpa membebani performa memori.

Kecepatan Enkripsi: Sangat Cepat (~Gbps)
Ukuran Ciphertext: Setara Plaintext
Peran Sistem: Enkripsi Payload File
Asimetris 2048-Bit

RSA (Rivest-Shamir-Adleman)

Algoritma berbasis faktorisasi bilangan prima raksasa. Menghilangkan kebutuhan bertukar kunci simetris di saluran publik tanpa rasa takut disadap.

Kekuatan Keamanan: Standar Perbankan
Proteksi Kunci: Kunci Publik & Privat
Peran Sistem: Enkripsi Kunci AES
Kurva Eliptik NIST P-256

ECC (Elliptic Curve Cryptography)

Generasi modern kriptografi asimetris dengan panjang kunci lebih ringkas namun kekuatan matematis setara RSA 3072-bit.

Efisiensi Signature: Sangat Ringkas (64-byte)
Kekuatan Kunci: Ultra Tinggi
Peran Sistem: Tanda Tangan Integritas
